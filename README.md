# On the Robustness of Distributed Machine Learning against Transfer Attacks

This repository contains the Python source code for the experiments of the paper "On the Robustness of Distributed
Machine Learning against Transfer Attacks", accepted at the AAAI Conference on Artificial Intelligence 2025.

## Experiments
### Preparation 

To set up the environment ```decentralized_robustness``` with all required packages just run:

```
conda env create -f environment.yml
conda activate decentralized_robustness
```

The following files need to be prepared:

- Adversarial images ```data/attacks.zip``` unpacked in place, i.e., the resulting folder is ```data/attacks```.

### Training

The experiments are launched with the wrapper script ```training_pipeline.py```, which essentially constructs a list of tasks from
the main.json file and then dispatches them with Ray.

It is parameterized as follows:

```
usage: training_pipeline.py [-h] [--verbose | --no-verbose] [--tasks TASKS] [--output_file OUTPUT_FILE] [--gpus GPUS]
                          [--tasks_per_gpu TASKS_PER_GPU] [--dataset DATASET] [--rounds ROUNDS] [--node_counts NODE_COUNTS]

optional arguments:
  -h, --help            show this help message and exit
  --verbose, --no-verbose
                        Prints command lines for scheduled task on the console. (default: False)
  --tasks TASKS         Comma separated list tasks to be executed.
  --output_file OUTPUT_FILE
                        File into which the Ray output is saved.
  --gpus GPUS           Comma separated list of GPUs to use. Sorted by PCI_BUS_ID.
  --tasks_per_gpu TASKS_PER_GPU
                        Number of tasks per GPU.
  --dataset DATASET     Dataset for training.
  --rounds ROUNDS       Comma separated list of specific rounds (and hence base models) to run the framework for. If nothing is
                        specified all five rounds are executed.
  --node_counts NODE_COUNTS
                        Comma separated list of specific number of nodes to run the framework for. If nothing is specified all
                        node counts are executed
```

Concretely, the following experiments need to be conducted:

```
python3 training_pipeline.py --task ensemble
python3 training_pipeline.py --task ensemble_diverse

python3 training_pipeline.py --task architecture_diverse 
python3 training_pipeline.py --task scheduler_diverse 
python3 training_pipeline.py --task optimizer_diverse 

python3 training_pipeline.py --task architecture+scheduler_diverse 
python3 training_pipeline.py --task architecture+optimizer_diverse 
python3 training_pipeline.py --task scheduler+optimizer_diverse

python3 training_pipeline.py --task architecture+optimizer+scheduler_diverse 
```

### Evaluation

The evaluation is launched with the script ```eval.py```, which reads the log files generated by Ray and evaluates the transferability of the adversarial images generated by the considered attacks based on the heterogenous models. The script will then return the (robustness) accuracies based on different voting schemes.
